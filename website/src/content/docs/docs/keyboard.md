## Global shortcuts

| Keys | Action |
| --- | --- |
| <kbd>⌃J</kbd> | Show labels on controls |
| <kbd>⌃⇧J</kbd> | Select and copy text |

You can [change both](/docs/settings/#shortcuts).

## Click mode

| Keys | Action |
| --- | --- |
| Label letters | Click the target |
| <kbd>⇧</kbd> with the last letter | Right-click the target |
| <kbd>Delete</kbd> | Remove the last letter you typed |
| <kbd>/</kbd> | Find a control by name |
| <kbd>Space</kbd> | Open the grid |
| <kbd>Tab</kbd> | Switch between labels and find |
| <kbd>Esc</kbd> | Cancel |

## Find

| Keys | Action |
| --- | --- |
| Any text | Filter by name |
| <kbd>↑</kbd> <kbd>↓</kbd> | Move between matches |
| <kbd>Return</kbd> | Choose the match |
| <kbd>⇧Return</kbd> | Right-click the match |
| <kbd>Delete</kbd> | Remove the last letter |
| <kbd>Tab</kbd> | Show labels on the matches |

## Marker group

| Keys | Action |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> | Move through the group |
| <kbd>Return</kbd> | Click the marker |
| <kbd>⇧Return</kbd> | Right-click the marker |

## Grid

| Keys | Action |
| --- | --- |
| <kbd>1</kbd> to <kbd>9</kbd> | Zoom into an area |
| <kbd>Return</kbd> | Click the center |
| <kbd>⇧Return</kbd> | Right-click the center |

## Select text

| Keys | Action |
| --- | --- |
| Any text | Find a word |
| <kbd>↑</kbd> <kbd>↓</kbd> | Cycle through matches |
| <kbd>Tab</kbd> | Show labels on the matches |
| <kbd>Return</kbd> | Set the first word, then the last |
