---
title: Keymaps
description: Choose which letters KeyHop uses for its labels.
---

The keymap decides which letters appear in labels. Choose one under **Jump labels** in Settings. **Standard** is the default.

| Keymap | How labels are assigned |
| --- | --- |
| **QWERTY** | Maps positions in the window to keyboard rows. |
| **Standard** | Uses every letter, beginning with `f j d k`. |
| **Home row** | Uses `a s d f g h j k l`. |
| **Custom** | Uses your own letters, in your order. |

## QWERTY

**QWERTY** treats the window as a keyboard. Upper-left targets start with <kbd>q</kbd>, lower-left targets start with <kbd>z</kbd>, and targets on the right side use the right side of each row. You can often guess a label before you read it.

Targets that share a region start with the same letter, followed by letters that tell them apart.

## Custom

1. Select **Custom**.
2. Enter 2 to 26 different letters, in the order you want them used.
3. Try them in **Live preview**.
4. Click **Apply**.

Fewer letters mean longer labels. Keep to the keys you reach fastest.
