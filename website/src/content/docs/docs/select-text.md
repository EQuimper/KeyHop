---
title: Select and copy text
description: Select a passage by its first and last words, then copy it.
---

Press <kbd>⌃⇧J</kbd> to select text in the active window. KeyHop reads the words on screen, so this works in apps that have no accessible text.

## Select a passage

1. Press <kbd>⌃⇧J</kbd>.
2. Type part of the first word. Press <kbd>Return</kbd> to set the start.
3. Type part of the last word. The violet highlight previews the range.
4. Press <kbd>Return</kbd>. KeyHop drags across the range and invokes Copy in the app.
5. Paste with <kbd>⌘V</kbd>.

You can start typing right away, while KeyHop is still reading the window.

## Choose between matching words

| Key | Action |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> | Cycle through the words that match |
| <kbd>Tab</kbd> | Show labels on the matches, then type one |
| <kbd>Delete</kbd> | Remove a letter from your search |
| <kbd>Esc</kbd> | Cancel |

## What affects the result

- **Selection follows the app.** KeyHop performs a mouse drag, so it works where a mouse drag can select text. The app decides what gets selected.
- **Keep things still.** Don't move the window or scroll while selecting.
- **Dense layouts can differ from the preview.** Tight columns and text inside images may select differently from the violet highlight.
- **English and French.** Word recognition is set up for these two languages.
