---
title: Click controls
description: Click, right-click, and find controls by name.
---

Press <kbd>⌃J</kbd> to put labels on the buttons, links, checkboxes, text fields, and other controls in the active window.

## Click with a label

Type the letters of a label. As you type, labels that no longer match disappear and the rest shrink to the letters you have left.

For a button labeled <span class="hop">jf</span>, type <kbd>j</kbd>, then <kbd>f</kbd>. Press <kbd>Delete</kbd> to take back a letter.

KeyHop sends a real mouse click to the center of the visible part of the control, so it works where the app expects a mouse.

## Right-click

Hold <kbd>Shift</kbd> while you type the last letter. For <span class="hop">jf</span>, type <kbd>j</kbd>, then <kbd>⇧F</kbd>.

Anywhere you finish with <kbd>Return</kbd>, such as a search result, a marker group, or the grid, use <kbd>⇧Return</kbd> instead.

## Find a control by name

Press <kbd>/</kbd> and start typing the control's name. KeyHop highlights the matches.

| Key | Action |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> | Move between matches |
| <kbd>Return</kbd> | Click the highlighted match |
| <kbd>Tab</kbd> | Switch back to labels, showing only the matches |

## Pick from a tight column

Rows of small targets, such as markers in a dense list, would crowd each other with one label each. KeyHop gives each column of three or more a single label ending in <span class="hop">›</span>.

1. Type the label marked <span class="hop">›</span>.
2. Use <kbd>↑</kbd> or <kbd>↓</kbd> to highlight a marker.
3. Press <kbd>Return</kbd> to click.

## Cancel

Press <kbd>Esc</kbd>. Switching apps also dismisses the labels, and so does any shortcut using <kbd>⌘</kbd>, <kbd>⌃</kbd>, or <kbd>⌥</kbd>, which then goes through to your app as usual.

If the window has no controls KeyHop can see, [use the grid](/docs/grid/).
